# Product Design + HCI Studio

A personal learning + evidence studio for building HCI, UX research, information architecture, interaction design, evaluation, and product thinking through real practice.

## Current focus
**Phase 1 · HCI + Human Behavior**  
**Week 1 · HCI Foundations**

Week 1 is intentionally observation-first: train the ability to notice how people interact with products before jumping into redesign solutions.

## Learning loop
Learn → Capture → Observe → Apply → Critique → Reflect → Evidence
